# Proposal

## Why

内容创作者、剪辑师和运营人员在制作文案时，需要反复在本地磁盘里翻找可用的视频、音频、图片素材，找到后还要人工观看/截图、抄录其中的文字、再手工润色成可发布的文案。这一流程高度重复、极其耗时，且散落在各处的素材一旦被遗忘就再也无法复用。

本项目提供一个运行在本机的 Web 应用：输入一个关键词，即可检索本地素材库中所有相关素材，自动提取其中的文字（视频/音频转写、图片 OCR、字幕文件直接解析），并调用云端大模型润色成通顺文案，同时把提取结果沉淀为素材标签，让素材库越用越好用。

典型的使用场景包括**动漫、漫画、剧集与游戏素材的二次创作**：为混剪找一段台词、为解说找一格画面、为笔记找游戏里的一句原文。这些素材的形态差别很大（外挂字幕、散图、录屏、长视频），但需求是同一条——**用关键词把散落在硬盘各处的那一段找出来**。

需要明确区分两件事：**文件类型**（视频、音频、图片、文本/字幕）是代码里必须存在的技术分类，因为它决定了「怎么读这个文件」；而**题材**（动漫、漫画、剧、游戏…）是用户自己的词汇，不作为代码中的分类维度——它由素材标签承载，住在数据库里。理由见 design.md 决策 11。

## What Changes

### 核心能力

- **关键词检索本地素材**：用户输入关键词，系统在本地素材库中检索匹配的视频、音频、图片、文本文件，支持按文件名、标签、已提取正文多路召回，并返回相关性排序结果。
- **本地素材库与标签归档**：用户可配置一个或多个本地素材目录，系统扫描并建立索引；提取出的文字可自动或手动转为素材标签，供后续检索复用。**题材（动漫/漫画/剧/游戏等）以标签形式表达**，不进入代码常量。
- **文字提取**：对视频/音频执行语音转写，对图片/视频帧执行 OCR 文字识别，产出结构化文本（含时间轴）；对字幕文件（`.srt` / `.vtt` / `.ass` / `.ssa`）则**直接解析导入**——文字本就现成，不经过任何识别引擎，也不下载任何模型。
- **文案润色**：调用云端大模型 API，将原始提取文本润色为通顺、可直接使用的文案/笔记。
- **设置界面与凭证管理（硬性要求）**：提供「设置」界面供用户自行填写 API Key；**任何 API Key 都不得硬编码在源码、配置文件或提交历史中**。用户未填写有效 Key 时，系统禁用润色功能并给出明确提示，其余功能（检索、提取）保持可用。

### 交付与工程化

- **交付形态**：本机运行的 Web 应用（本地启动服务 + 浏览器访问），不打包桌面客户端。
- **开源交付物**：提供中文 `README.md`（项目介绍、功能说明、运行步骤）与 `.gitignore`，确保 `node_modules` 等依赖目录、以及存放 API Key 的敏感文件不会被提交到 GitHub。
- 项目最终提交到 GitHub 公开仓库。

## Capabilities

### New Capabilities

- `material-library`: 本地素材目录配置、扫描与索引、素材元数据管理、标签归档与复用。
- `material-search`: 以关键词为入口，跨素材的文件名、标签、已提取文本进行检索并排序返回结果。
- `text-extraction`: 从视频/音频中语音转写、从图片/视频帧中 OCR 提取文字、从字幕文件（`.srt` / `.vtt` / `.ass` / `.ssa`）中直接解析导入，均产出带时间轴的结构化文本。
- `text-polish`: 调用云端大模型对提取文本进行润色，产出文案/笔记，并在凭证缺失时安全降级。
- `credential-settings`: 设置界面中的 API Key 录入、校验、本地安全存储与脱敏展示，以及密钥不得入库的约束。

## Impact

- **全新代码库**：当前仓库仅有 `openspec/` 规划目录，所有应用代码均为新增。
- **技术栈**：Node.js 后端服务 + 浏览器前端；本地索引存储；本地 OCR / 语音转写引擎；云端 LLM 用于润色。
- **外部依赖**：
  - 云端大模型 API（用户自备 Key，计费归属用户）；
  - 本地 OCR 引擎与语音转写模型（首次使用需下载模型文件，体积较大）。
- **敏感信息**：API Key 由用户在运行时录入，落盘位置需加入 `.gitignore`，且需在 README 中明确告知用户不要提交该文件。
- **平台**：Windows 为首要目标平台，架构上不排除后续跨平台。
- **非目标**：
  - 不做网络平台素材爬取/下载，不涉及在线素材的版权合规处理。
  - 不做桌面客户端打包；不做多人协作与云端同步。
  - **不做中文以外语言的语音转写与 OCR**（日文、英文等列入未来规划）。注意此限制只针对「从语音和画面里认出文字」：字幕文件的直接解析不「识别」任何东西，日文字幕照常导入、照常可搜。
  - 不把「题材」做成代码里的分类维度或筛选器——题材由标签承载。
  - 不做漫画压缩包（`.cbz` / `.cbr`）的解包与逐页识别；漫画素材本期以散图形式支持。

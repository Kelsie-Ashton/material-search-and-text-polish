# Spec Delta

## Purpose

调用云端大模型，把素材中提取出的原始文字润色为通顺、可直接使用的文案或笔记，并保存润色结果以供检索与归档；在用户尚未配置凭证时安全降级，不阻断其余功能。

## ADDED Requirements

### Requirement: 文案润色

系统 SHALL 调用云端大模型接口，将用户选定的素材提取文本润色为通顺、连贯、可直接使用的文案或笔记。润色 MUST 保留原始文本的事实信息，MUST NOT 编造原文中不存在的事实、数据或结论。

#### Scenario: 对单个素材的提取文本润色

- **WHEN** 用户对一个「已提取」素材请求润色，且已配置有效凭证
- **THEN** 系统将该素材的提取文本发送至云端模型，并将润色后的文案保存到该素材上

#### Scenario: 多素材合并润色

- **WHEN** 用户选中多个「已提取」素材并请求合并润色为一份笔记
- **THEN** 系统将所选素材的提取文本一并作为输入，产出一份整合后的笔记并标明其来源素材

#### Scenario: 润色保留原意

- **WHEN** 原始提取文本中包含具体的事实、数字或结论
- **THEN** 润色结果保留这些信息的含义，不替换为原文中不存在的表述

#### Scenario: 输入文本过长

- **WHEN** 待润色的提取文本超出模型单次可处理的长度上限
- **THEN** 系统分段处理后再汇总输出，或明确告知用户该素材过长无法一次性润色，且 MUST NOT 静默截断并丢弃内容

### Requirement: 未配置凭证时安全降级

当用户尚未配置有效的 API Key 时，系统 SHALL 禁用润色相关的操作入口，并 SHALL 给出指向设置界面的明确提示。此时检索与文字提取功能 MUST 保持完全可用。

#### Scenario: 未配置凭证时润色入口禁用

- **WHEN** 用户未配置任何 API Key 并访问润色功能
- **THEN** 润色按钮呈禁用状态，并显示提示说明需先前往设置界面填写 API Key

#### Scenario: 未配置凭证不影响其他功能

- **WHEN** 用户未配置任何 API Key
- **THEN** 素材扫描、关键词检索、标签归档与文字提取功能均可正常使用

#### Scenario: 凭证在运行中被补全

- **WHEN** 用户在设置界面成功保存了一个有效的 API Key
- **THEN** 系统无需重启即可解除润色功能的禁用状态

### Requirement: 润色结果的保存与对照

系统 SHALL 将润色结果与原始提取文本分别保存，并 SHALL 允许用户对照查看原始文本与润色后文本。

#### Scenario: 对照查看原文与润色结果

- **WHEN** 用户打开一个已润色的素材
- **THEN** 系统同时展示原始提取文本与润色后文本，二者可区分且互不覆盖

#### Scenario: 重新润色覆盖旧结果

- **WHEN** 用户对已有润色结果的素材再次发起润色
- **THEN** 新的润色结果替换旧结果，原始提取文本保持不变

### Requirement: 润色失败的可读反馈

系统 SHALL 在润色调用失败时向用户展示可读的失败原因，并 SHALL 保留原始提取文本不受影响。

#### Scenario: 调用失败

- **WHEN** 润色请求因网络异常、凭证无效、额度耗尽或服务端错误而失败
- **THEN** 系统展示对应类别的失败原因，且该素材的原始提取文本与已有润色结果 MUST NOT 被破坏

#### Scenario: 凭证无效的区分提示

- **WHEN** 润色失败的原因是 API Key 无效或无权限
- **THEN** 系统明确提示凭证无效，并引导用户前往设置界面更新 API Key，而不是笼统提示网络错误

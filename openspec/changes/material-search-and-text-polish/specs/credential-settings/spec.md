# Spec Delta

## Purpose

提供让用户自行录入与管理云端模型 API Key 的设置界面，负责凭证的本地安全存储、脱敏展示与有效性校验，并确保任何密钥都不会被写入源码、配置文件或提交到代码仓库。

## ADDED Requirements

### Requirement: 设置界面录入凭证

系统 SHALL 提供一个设置界面，供用户自行填写云端模型服务的 API Key 及可选的服务地址与模型名称。系统 MUST NOT 在源码、构建产物或仓库配置文件中内置任何 API Key 或默认密钥。

#### Scenario: 用户自行填写 API Key

- **WHEN** 用户在设置界面输入 API Key 并保存
- **THEN** 系统保存该凭证并将其用于后续的润色请求，界面提示保存成功

#### Scenario: 源码中不含任何密钥

- **WHEN** 审查项目源码、构建产物与仓库中的配置文件
- **THEN** 其中 MUST NOT 包含任何真实的 API Key 或可用于调用付费服务的默认密钥

#### Scenario: 保存空白凭证

- **WHEN** 用户在未填写 API Key 的情况下点击保存
- **THEN** 系统拒绝保存并提示该字段为必填，原有凭证保持不变

### Requirement: 凭证的有效性校验

系统 SHALL 允许用户对已填写的凭证发起连通性测试，并 SHALL 将校验结果以成功或具体失败原因的形式反馈给用户。

#### Scenario: 校验通过

- **WHEN** 用户填写了一个有效且有权访问目标模型的 API Key 并点击测试
- **THEN** 系统向该服务发起一次轻量请求，成功后提示凭证有效

#### Scenario: 校验失败

- **WHEN** 用户填写的 API Key 无效、已过期或无访问权限
- **THEN** 系统提示校验失败并给出可读原因，且 MUST NOT 将无效凭证标记为可用

### Requirement: 凭证的本地存储与脱敏展示

系统 SHALL 将凭证保存在本机独立于源码的存储位置，并 SHALL 在界面与日志中仅展示脱敏后的形式（如仅显示末四位），完整密钥 MUST NOT 出现在界面回显、日志或错误信息中。

#### Scenario: 界面脱敏回显

- **WHEN** 用户已保存凭证并再次打开设置界面
- **THEN** 系统仅展示脱敏后的凭证形式，不完整回显原始密钥

#### Scenario: 日志与错误信息脱敏

- **WHEN** 系统因调用失败而输出日志或错误信息
- **THEN** 输出内容中 MUST NOT 包含完整的 API Key

#### Scenario: 清除已保存的凭证

- **WHEN** 用户点击清除凭证
- **THEN** 系统删除本地保存的凭证，并将润色功能恢复为未配置凭证时的禁用状态

### Requirement: 凭证存储位置排除在版本控制之外

系统 SHALL 将凭证存放位置排除在版本控制之外，并 SHALL 通过 `.gitignore` 与项目文档明确告知使用者该文件不得提交。

#### Scenario: 凭证文件被忽略

- **WHEN** 凭证已保存到本地存储位置，且用户执行 `git status`
- **THEN** 该凭证文件不出现在待提交变更中

#### Scenario: 文档明确提示

- **WHEN** 使用者阅读项目 README 的配置说明
- **THEN** 文档明确说明 API Key 需在设置界面填写、存放位置已被忽略、且禁止将其提交到仓库
